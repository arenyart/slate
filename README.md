# Slate — Storyboard & Screenplay Studio (Clean Edition)

A lightweight, standalone web-based storyboard drawing and Hollywood-standard screenplay studio—starting from a clean blank canvas with zero preloaded demo content.

## Quick Start
1. Unzip `slate-storyboard-studio-clean.zip`.
2. Open `index.html` directly in any modern desktop browser (Chrome, Safari, Firefox, or Edge) — no build step or server required.
3. Your work, custom panel sizes, and theme choice save automatically to your browser's `localStorage`. Use **File → Save Project Backup (.json)** for portable backups.

## Features
- **Multi-Layer Drawing Canvas**: Ink Pen (`B`), Pencil (`P`), Marker (`M`), Eraser (`E`), Line (`L`, hold `Shift` for 45° snap), Rectangle (`R`), Ellipse (`O`), Camera Arrow (`A`), Flood Fill (`G`), Text Callout (`T`), 3 layers (**Rough**, **Tone**, **Ink**), Rule of Thirds & Action/Title Safe overlays, Onion Skinning, reference image import, and 25-step Undo/Redo (`Ctrl/Cmd+Z`).
- **Drag-to-Reorder & Resizable Workspace**: Drag shots directly in the bottom **Shot Timeline** or **Board** overview grid; drag the vertical or horizontal panel dividers to resize the canvas, screenplay panel, or timeline strip (double-click any divider to reset).
- **Paginated Hollywood Screenplay Editor**: Automatic 54-line US Letter pages (~1 min/page) with Page 2+ numbering, orphan/widow protection, live page-eighths & runtime estimation, Scene Heading / Action / Character / Parenthetical / Dialogue / Transition / Shot formatting (`Tab` cycles types, `Enter` advances, `Ctrl/Cmd+1–7` shortcuts), `+ Beat` structural snippets, and Title Page editor.
- **Unified File Menu & Animatic**: Start a new blank project, open/save `.json` projects, import/export `.fountain` screenplays, export `.png` frames, and print/save paginated PDF Screenplays or 2×3 Storyboard Sheets—plus preview shot timing in the **Animatic** player.
- **3-Way Studio Themes**: Switch seamlessly between **Dark**, **Studio Grey**, and **Light** modes from the top bar.
